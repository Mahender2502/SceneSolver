# 🔍 SceneSolver

SceneSolver is an **AI-powered forensic investigation platform** that analyzes crime scene images and generates summaries using computer vision and large language models (LLMs).

## Features
-  Upload and analyze crime scene images
-  Detect forensic evidence using:
  - CLIP for crime classification
  - Vision Transformers (ViT) & YOLOv8 for object detection
-  Generate automated crime scene summaries using LLMs
-  Store cases, images, and summaries in MongoDB
-  Frontend built with React.js, deployed on AWS/Heroku/Vercel

## 🛠️ Tech Stack
- **Frontend:** React.js  
- **Backend:** Flask / Python (for ML model APIs)  
- **Database:** MongoDB  
- **Machine Learning:** PyTorch, TensorFlow  
- **Models Used:** CLIP, ViT, YOLOv8 
- **Deployment:** AWS / Vercel / Heroku
